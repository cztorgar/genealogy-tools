# Místopis

Obecné místopisné rešerše pro matriční výzkum — farnosti, osady, historické názvy, správní příslušnost,
uložení matrik a ztráty. **Bez osobních dat.** Jedna podsložka = jedno místo nebo oblast; strojová podoba
(svazky, ID, čísla popisná se souřadnicemi) v `mcp/czech-archives/gazetteer/`. Historické mapy jako
skládatelné vrstvy stahuje [`tools/mapy/`](../../tools/mapy/README.md).
