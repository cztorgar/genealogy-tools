# Katalog pramenů

Přehled typů pramenů pro české země — co existuje, pro jaké období, co se z toho dá ověřit a kde to
hledat. Podrobnosti ke konkrétním portálům: [`../archivy/`](../archivy/). Položky označené
**[ověřit]** jsou z průzkumu, ale nejsou potvrzené.

## Co se dá kde automatizovat

Jmenné indexy prakticky neexistují (výjimky: policejní přihlášky NA, VÚA, holocaust.cz, přepis indexů
SOA Třeboň, index 1921 na MyHeritage). Všechno ostatní = najít správný svazek a číst snímky →
`czech-archives` (vyhledání svazku, stažení snímku) + `reader` (přepis).
